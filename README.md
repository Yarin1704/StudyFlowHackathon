# StudyFlow ⏱️📚

## Overview
StudyFlow is a deterministic learning scheduler developed collaboratively during an intensive engineering hackathon. Designed to optimize study habits and time management, the application automates the creation of structured learning plans, helping students manage their academic workload efficiently and predictably.

## Live Demo
🚀 **[View the live application on Vercel](https://study-flow-rust-pi.vercel.app/)**

## Key Features
* **Deterministic Scheduling Algorithm:** Generates precise, predictable, and optimized study schedules based on user-defined constraints and deadlines.
* **.ics Calendar Integration:** Seamlessly exports generated study plans into `.ics` format, allowing users to import their schedules directly into Google Calendar, Apple Calendar, or Outlook.
* **Real-Time Data Management:** Utilizes a cloud-based backend powered by **Supabase** for fast, secure, and synchronized user data storage.

## Tech Stack
* **Frontend/Framework:** [e.g., React / Next.js / Node.js]
* **Database & Backend (BaaS):** Supabase (PostgreSQL)
* **Calendar Integration:** `.ics` file generation and parsing
* **Core Logic:** Deterministic scheduling algorithm

## The Hackathon Context
This project was brainstormed, designed, and developed within a strict time limit during an engineering hackathon. It highlights rapid prototyping, effective teamwork, and quick integration of third-party cloud services to solve real-world problems.
